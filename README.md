# Soenneker.Clamav.Runners.Windows

Automation for maintaining `Soenneker.Clamav.Windows` from the latest stable official ClamAV Windows x64 portable release.

The runner itself is MIT-licensed. Generated native packages retain ClamAV's GPL-2.0-only license, preserve upstream and third-party license files, and record the exact corresponding source archive in `SOURCE.txt`.
